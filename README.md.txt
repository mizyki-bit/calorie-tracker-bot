# Программный комплекс «Telegram-платформа для интерактивного учета нутриентов и энергозатрат»

### Общее описание разработки
Данный программный продукт представляет собой автоматизированное решение в виде мессенджер-бота, нацеленное на систематизацию ведения персонального учета энергетической ценности рациона и физической активности. Приложение осуществляет динамическое вычисление полученных калорий, калькуляцию затраченной энергии, а также формирует результирующий суточный баланс пользователя.

### Примененный стек технологий
- Базовый язык: Python 3.10+
- Сетевой интерфейс: Библиотека pyTelegramBotAPI (синхронное исполнение)
- Методология: Объектно-ориентированная парадигма (ООП). Задействованы механизмы наследования от базовой структуры, сокрытие внутренних данных через приватные поля, а также полиморфное поведение функций при определении знака калорийности.
- Файловый менеджмент: Регистрация логов и сохранение истории действий в локальный текстовый файл `history.txt`.

### Порядок развертывания системы
1. Склонируйте или перенесите компоненты программы в рабочую директорию.
2. Инициализируйте консоль в целевой папке и осуществите загрузку пакетов:
   ```bash
   pip install -r requirements.txt
   ```

### Инструкция по запуску скрипта
1. Сгенерируйте секретный ключ доступа у сервиса `@BotFather`.
2. Поместите полученную строку в конфигурационный параметр `API_TOKEN` внутри главного файла `bot.py`.
3. Активируйте исполнение приложения через командную строку или среду Thonny:
   ```bash
   python bot.py
   ```

### Сценарии взаимодействия (Примеры запросов)
- Директива `/start` — первичный запуск диалогового окна и отображение кастомных кнопок навигации.
- Элемент интерфейса `Добавить еду` -> Ввод параметров вида `Творог 150` — производит фиксацию записи в положительном регистре.
- Элемент интерфейса `Добавить тренировку` -> Ввод параметров вида `Скакалка 200` — производит фиксацию записи в отрицательном регистре.
- Текстовый ввод наименований (например: `банан` или `плавание`) — мгновенный вывод справочной информации из встроенного словаря данных.
- Элемент интерфейса `Баланс калорий` — агрегация всех существующих записей и генерация отчета.
